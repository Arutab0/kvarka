### Что делает эта функция?

В Next.js сервер получает от клиента JSON с телом запроса (`body`). Внутри этого JSON клиент передает объект `utm` (собранный с помощью нашего JS-скрипта из URL браузера).

Функция `parseUtm` берет пришедшие данные, проверяет их на безопасность и чистит:

1. Убеждается, что `value` — это действительно объект, а не `null`, число или строка.
2. Пробегается по разрешенному списку ключей (`keys`).
3. Для каждого ключа проверяет: если значение является непустой строкой, очищает его от случайных пробелов по краям (`.trim()`) и записывает в итоговый объект `utm`.
4. Если ни одного валидного ключа не нашлось — возвращает `undefined` (чтобы не хранить пустые объекты `{}` в базе/файле).

---

### Что означают эти ключи? (Маркетинговые UTM-метки)

Это стандартные международные параметры интернет-маркетинга. Когда кофейня запускет рекламу в Instagram, Яндексе, Google или Telegram, маркетолог формирует ссылки с такими параметрами.

Вот что каждый из них значит на примере:

Представь, что клиент кликнул по ссылке в Instagram:

`[https://kvarta.by/?utm_source=instagram&utm_medium=cpc&utm_campaign=autumn_sale&utm_content=button_buy&utm_term=coffee_minsk](https://kvarta.by/?utm_source=instagram&utm_medium=cpc&utm_campaign=autumn_sale&utm_content=button_buy&utm_term=coffee_minsk)`

| Ключ | Что означает | Пример из ссылки | Зачем менеджеру кофейни? |
| --- | --- | --- | --- |
| **`source`** | **Источник рекламы** *(Откуда пришел)* | `instagram`, `yandex`, `vk`, `telegram` | Понять, какая площадка приносит заявки (Instagram или Яндекс). |
| **`medium`** | **Тип трафика / Канал** | `cpc` (клики/контекст), `social` (пост), `email`, `story` | Понять, платный это клик по таргету или бесплатный переход из шапки профиля. |
| **`campaign`** | **Название рекламной кампании** | `autumn_sale`, `drip_coffee_promo`, `minsk_center` | Узнать, какая конкретно акция сработала. |
| **`content`** | **Содержание / Вариант объявления** | `banner_red`, `video_reels`, `button_order` | Понять, какой именно баннер или креатив зацепил человека. |
| **`term`** | **Ключевое слово** *(для поиска)* | `купить свежий кофе минск`, `кофе подписка` | Увидеть, по какому поисковому запросу в Яндексе человек вышел на сайт. |
| **`referrer`** | **Страница перенаправления** | `[https://l.instagram.com/](https://l.instagram.com/)` | Технический источник — адрес сайта, с которого пользователь совершил переход. |

### Итог:

Эта функция как раз **полностью закрывает требование ТЗ**:

> *«Заявки идут с рекламы. Менеджеру важно знать, откуда пришёл клиент: из какой рекламы, с какого объявления, с какой страницы.»*

Когда менеджер получит заявку в Telegram или увидит её в JSON/SQLite, там будет четкий блок:

```json
{
  "name": "Артем",
  "phone": "+375291234567",
  "utm": {
    "source": "instagram",
    "medium": "cpc",
    "campaign": "autumn_sale",
    "content": "banner_red"
  }
}

```

Код написан строго, с хорошей типизацией TypeScript (`unknown`, `Record<string, unknown>`). Всё сделано отлично!
